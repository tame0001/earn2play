This folder contains circuit design using KiCAD.

# 7-Segment Display

Each segment has 20 LEDs that draw 5mA each.
So, the total current drawn by a segment is 20 x 5mA = 100mA
And each digit will draw 7 x 100mA = 700mA

There will be 4 digits on the display, so the total current drawn will be 4 x 700mA = 2.8A
The power source will be 5V 3A.
